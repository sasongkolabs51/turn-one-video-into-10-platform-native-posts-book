### 11.4.6 Sprint Launchpad

Use this checklist before starting your timer to ensure you can launch a sprint in under sixty seconds with zero mental friction.

- [ ] Hub template link is accessible and ready
- [ ] Prompt library is open and current
- [ ] AI tool is open in the correct tabs
- [ ] Scheduler is open and ready
- [ ] Timer is set for the designated sprint duration
- [ ] Notifications are silenced on all devices
- [ ] Sprint window is blocked on my calendar

If you can't tick every box:
- If you find yourself searching for links or tabs, the subtle trap of manual ignition is returning; rebuild your launchpad immediately to remove the decision fatigue.

### 11.4.7 Fifteen-Minute Microsprint

Use this checklist when a full hour is not available, narrowing your sprint to its essential steps to maintain momentum.

- [ ] Open Decision Matrix and identify the top-scoring pillar
- [ ] Open the Twitter prompt template
- [ ] Paste the Core Thesis and Quotable Lines from the Hub
- [ ] Set a timer for fifteen minutes
- [ ] Generate the thread
- [ ] Triage in five minutes using the Approve / Lightly Edit / Flag framework
- [ ] Schedule the approved thread in your scheduler

If you can't tick every box:
- If you miss the fifteen-minute window entirely, escalate to Level 2 and requeue an archive post to prevent the guilt-driven spiral of system abandonment.

### 11.4.8 Monthly Voice Check

Use this checklist on the first Monday of each month to detect subtle voice drift and add reinforcing constraints to your prompts.

- [ ] Select one platform to review for this month
- [ ] Read the last four weeks of posts from that platform in sequence
- [ ] Ask: Does the opening hook style remain consistent?
- [ ] Ask: Are my signature phrases and contractions still present?
- [ ] Ask: Has the emotional register shifted (warmer, colder, more formal)?
- [ ] Identify one specific drift pattern, if any
- [ ] Add one reinforcing constraint to the relevant prompt template
- [ ] Regenerate one test post and verify the drift is corrected

If you can't tick every box:
- If you detect automation without accountability leading to drift, remember that one specific constraint added today prevents the slow creep of generic AI writing tomorrow.
