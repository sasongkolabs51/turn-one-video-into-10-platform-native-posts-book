## 📄 PERSONAL FINGERPRINT — v1, LOCKED

**Structure:** One shared foundation + two toggleable sub-modes.

### Shared Foundation (both sub-modes)

| Dimension | Specification |
|---|---|
| **Direct address** | Second-person "you" throughout, with occasional first-person "I" for authenticity markers |
| **Concrete anchor opening** | Scene or vivid image before thesis — never statistic, definition, or unsupported claim |
| **Conversational transitions** | Questions or "here's what" pivots. **Banned:** "Furthermore," "Moreover," "Additionally," "In conclusion," "It should be noted that" |
| **Register** | Beginner-friendly (same floor as Book Author) |
| **Global bans** | All six rhetorical contrast tells + fragment-stack summary ban |

### Narrative Personal Sub-Mode

**Activation:** Post's purpose is to *tell a story* that illustrates a lesson.

| Dimension | Specification |
|---|---|
| **Hook** | ✅ Short declarative thesis allowed *when it's a metaphor or framing device* ("Writing online is a game.") → time-stamped scene anchor → concrete sensory detail → narrative set-up |
| **Rhythm** | Long flowing paragraphs with clauses and em-dashes → short punchy strikes at emotional peaks → return to flow |
| **Lexicon** | First-person precision; specific named references; self-deprecating honesty; informal vocabulary ("lost their shit," "dude"); direct address; emotional peaks named directly |
| **Argument** | Scene → complication → lesson → application → outcome → varied closing |
| **Emotional register** | Warm, self-aware, vulnerable, honest about failure → hope without cheerleading → identity confidence without arrogance |
| **Closing** | **Varies per post** — no fixed closing move (banned: identity-affirming close) |

**Narrative Negative Constraints:**

| Structure | Status |
|---|---|
| Identity-affirming closing ("I was no longer X. I was Y.") | ❌ Banned |
| Fragment-stack summary | ❌ Banned (global) |
| Six rhetorical contrast tells | ❌ Banned (global) |
| Short declarative thesis opening (metaphor/frame only) | ✅ **Allowed signature** |
| Informal vocabulary | ✅ Preserve |
| Self-deprecating humor | ✅ Preserve |
| Concrete parenthetical specificity ("(wheat)") | ✅ Preserve |

### Instructional Personal Sub-Mode

**Activation:** Post's purpose is to *teach a system, framework, or method*.

| Dimension | Specification |
|---|---|
| **Hook** | Second-person scene-setter ("Picture yourself...") → vision of ideal state → tension between ideal and reality → framing question |
| **Rhythm** | Short thematic paragraphs (2–4 sentences) → question-based transitions → bullet expansions → punchy headers |
| **Lexicon** | Second-person instructional voice; concrete business vocabulary; metaphor-as-structure; measured but warm |
| **Argument** | Vision → question → thesis → framework (three-pillar metaphor) → self-assessment → balancing acts → closing question |
| **Emotional register** | Measured warmth → practical reassurance → professional respect for reader autonomy → understated encouragement |
| **Closing** | Direct question to reader (varies by post content) |

**Instructional Negative Constraints (v2 upgrade — all seven banned):**

| Banned Structure | Original Pattern |
|---|---|
| Comparative pivots | "Accountability defines the deepest difference...—more than flexible hours" |
| Triple antithetical parallelism | "Passion and skill without... Marketable skills without... Financial need without..." |
| Comparative pivot | "Your name carries more weight than any corporate brand." |
| Abstract aphorism | "This reality permeates your professional existence." |
| Aphoristic summary | "This living document creates freedom through intentional structure." |
| Aphoristic summary | "Uncertainty, respected and planned for, fuels continuous growth." |
| Colon-subtitle headers | "The Fundamental Shift: From Corporate Cog to Captain of Your Ship" |

**Preserved signatures (not banned):**
- Question-based transitions
- Metaphor-as-structure (the *metaphor itself* is preserved; the *colon-subtitle header format* is banned)
- Bolded lead-in list format
- Second-person vision-setting
